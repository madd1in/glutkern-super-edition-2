# GLUTKERN — Super Edition 2

Ein eigenständiges Three.js-Browsergame. Öffne `index.html` oder spiele die veröffentlichte GitHub-Pages-Version.

## Steuerung

- Bewegen: `W`, `A`, `S`, `D`
- Zielen und feuern: Maus / linke Maustaste
- Dash: `Shift`
- Wirbel: `Leertaste`
- Orbitalschlag: `E`
- Ton / Grafik / Pause: `M` / `V` / `P`

## Super Edition 2.1

- Neuer MP3-Soundtrack „Marios Pilzpfad"
- Ruhigeres Bloom und kontrastreicheres Tone-Mapping gegen Überbelichtung
- Grafikmodus zur Laufzeit mit `V` umschaltbar
- Audio-Parameter werden gegen ungültige Werte abgesichert

## Deployment

Jeder Push auf `main` wird automatisch über GitHub Pages veröffentlicht.
