# GLUTKERN — Super Edition 2

Ein eigenständiges Three.js-Browsergame. Öffne `index.html` oder spiele die veröffentlichte GitHub-Pages-Version.

## Steuerung

- Bewegen: `W`, `A`, `S`, `D`
- Zielen und feuern: Maus / linke Maustaste
- Dash: `Shift`
- Wirbel: `Leertaste`
- Orbitalschlag: `E`
- Ton / Pause: `M` / `P`

## Deployment

Jeder Push auf `main` wird automatisch über GitHub Pages veröffentlicht.
